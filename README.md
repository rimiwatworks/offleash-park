# 公園オフリーシュ大作戦

リードを外した茶白のワンちゃんを操作して、公園に落ちているテニスボールを集めるステルスゲームです。係員さんの懐中電灯に見つからないように集め、入口の飼い主のところへ戻ればクリアです。90年代の3Dチャット風の見た目で、ワンちゃんを後ろから見るサードパーソン視点で遊びます。

## 遊び方

`index.html` をブラウザで開くだけで動きます（three.js r128 を cdnjs から読み込みます）。

- WASD / 矢印キー: 移動（カメラの向きが基準）
- マウスドラッグ / Q・E: カメラを回す
- V: 犬目線に切り替え（左右で向きを変え、前後で進む）
- スマホ: 画面の左半分で移動、右半分でカメラ

## ルール

- ボールを全部拾って、入口の光る柱（飼い主）へ戻るとクリア
- 懐中電灯の光に入ると「？」のゲージがたまり、「！」になるとアウト
- 茂みの中なら見つかりにくく、木の幹は視線をさえぎる
- ステージが進むと公園が広くなり、係員さんが増える
